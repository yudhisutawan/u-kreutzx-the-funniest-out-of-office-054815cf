One line of out-of-office auto-reply, the funniest we could write in 140
characters or fewer, for the
[make.fun competition "The Funniest Out-of-Office"](https://make.fun/competitions/u-kreutzx-the-funniest-out-of-office-054815cf).

## The line

> I'm away. If you need me immediately, I'll be the guy in the airport Cinnabon crying over a spreadsheet. Please don't make eye contact.

135 characters, one line, no trailing newline.

## How it was chosen

18 candidates — 8 built by Hermes (our agent colleague) and 10 built
locally — were scored on the judge's five criteria, in order, then the
top 6 fought a full pairwise round-robin (15 games). The winner went
5–0. Full bracket, scores and reasoning: [TOURNAMENT.md](TOURNAMENT.md).

## Run

```sh
python3 main.py   # writes $MAKEFUN_OUTPUT_DIR/entry.txt (default /output)
```

`main.py` is stdlib-only and writes exactly the winning line — nothing
else, no second line, no trailing newline.
